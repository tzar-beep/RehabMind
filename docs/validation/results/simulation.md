# Personalization simulation: results

Generated by `uv run python -m app.scripts.simulate_learners --write` (300 synthetic learners per cell, ability ~ N(0, 1.5), 300 exercises each, seed 7). Method and limits: [personalization.md](../personalization.md).

**Productive band** = the learner's true chance of success is 60%-90%. *Too hard* < 50%, *too easy* > 95%. *Error runs* = times a learner got 3 wrong in a row (per 300 exercises).
